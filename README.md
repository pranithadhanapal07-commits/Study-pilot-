# Study-pilot-
AI-powered study assistant that helps students analyze study materials, identify important topics, and prepare smarter.

## Features
- Upload PDFs, notes, PPTs, and previous year questions
- Identify important topics
- Analyze PYQ frequency
- Generate personalized study plans
- Estimate study time
- AI-based recommendations

## Technologies
- Python
- Artificial Intelligence
- Machine Learning
- Web Development
